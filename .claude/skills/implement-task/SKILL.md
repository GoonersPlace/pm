# Skill: implement-task

Use for a normal feature/task implementation.

1. Read `CLAUDE.md`, relevant docs, memory, and module `AGENTS.md`.
2. Inspect existing code before editing.
3. Identify contracts impacted. If architecture/dependency/schema/API/core constraint changes are needed, stop and request approval.
4. For non-trivial work, create a short plan.
5. Implement only requested scope with the simplest maintainable solution.
6. Add/update tests.
7. Run relevant quality gates from `docs/TESTING.md`.
8. Update docs only when behavior/contract legitimately changed.
9. Run `log-task`.
10. Report changes, checks, results, and remaining issues.
