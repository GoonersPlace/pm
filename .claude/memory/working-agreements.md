# Working Agreements

- AI control level: Balanced.
- Explain important decisions thoroughly.
- When two materially different valid approaches exist, present them to the owner rather than silently choosing.
- For small/reversible ambiguity, choose the simplest safe approach and record the assumption.
- Do not refactor outside task scope; report unrelated issues instead.
- Ask before architecture/dependency/schema/API/algorithm/constraint/build-system/large-refactor changes.
- AI may create files within task scope.
- Important source/config/docs files should not be deleted/moved without approval.
- Do not commit, push, merge, or switch branches unless explicitly requested.
- `.env` is readable when necessary but read-only; never expose secrets.
