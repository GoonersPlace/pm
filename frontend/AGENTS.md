# Frontend agent rules

Applies to `frontend/`.

- React + TypeScript + Vite + Tailwind.
- Follow `docs/UI_GUIDELINES.md`.
- TypeScript strict; avoid `any`.
- Keep API client types aligned with `docs/API.md`; do not invent backend fields.
- Desktop-first timetable UX, basic responsive behavior for tablet/mobile.
- Accessible labels, keyboard controls, sufficient contrast, and text/icon cues in addition to color.
- Do not add npm dependencies without owner approval.
